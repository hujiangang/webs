# 菌子主题与主页实现

更新：2026-10-06。布局依据作者提供的方块世界 / Klotski 六张参考图。

## 三页主页

| 页面 | 已实现内容 |
| --- | --- |
| 商店 | 爆破弹、小木锤、重排、十字消除四种道具；显示库存与金币价格；余额足够时扣金币并增加一个道具，余额不足时提示 |
| 游戏（默认） | 顶部头像、体力、金币、右侧展开菜单；纵向关卡路径，当前／已通关／未解锁状态；当前关卡开始按钮 |
| 图鉴 | 读取配置的菌子卡片列表，支持纵向滚动；点击显示图片、介绍、生长环境和备注 |

底部页签与左右滑动保留。关卡列表仅能浏览当前关和已通过关卡，保留紧邻的一关锁定预览；向未解锁方向拖动会回弹，不能继续浏览后续锁定关卡。最多绘制附近 12 个节点。锁定关卡不能进入，已通过关卡可以重玩。

头像和菜单中的“信息”打开个人信息卡。菜单中的“设置”只提供音乐、音效、震动三项，状态会保存；无邮件、联系客服、订阅入口。浏览器开发环境额外显示验收入口，微信环境不显示。

## 美术与局内 UI

- 主页采用宝蓝到青蓝渐变，局内使用紫蓝背景；蓝框奶油色弹窗和饱满绿色主要按钮统一采用立体玩具质感。
- 棋盘采用相连的深蓝灰底座、低对比交错底格和轻凹槽；普通棋子缩小到格子的 88%，留出间隙。
- 道具栏与商店使用同一套本地 RGBA 图集：紫色爆破弹、蓝金木锤、双色重排、蓝色十字。特殊棋子也使用该图集，消除特效继续由程序绘制。
- 收集目标、步数、分数采用简洁顶栏；补充道具、个人信息、设置和结算采用统一面板。
- 基础菌子由作者设计，目前保留现有四张菌子图和其他尚未替换的基础／障碍资源。没有据临时图片编造菌种名称或食用知识。
- 特殊元素保留已经确认的双箭头、爆破弹、小爆弹、流星球和彩虹球，重新统一圆润造型、饱和配色和高光。特效由程序绘制，编号、触发规则和覆盖范围保持兼容。

## 资料和价格配置

图鉴配置：`assets/resources/config/mushroom-journal.json`。

```json
{
  "entries": [{
    "id": "mushroom-01",
    "name": "菌种名称",
    "image": "texture/match3/objects/cells/obj0",
    "description": "作者提供的介绍",
    "habitat": "生长环境",
    "note": "其他备注"
  }]
}
```

当前四条为待命名资料占位；以后按相同格式增加条目即可。图片路径是 resources 下的 SpriteFrame 路径，不带扩展名。长篇资料需要按移动端阅读长度整理，当前详情面板适合简短介绍。

道具仍使用 `assets/resources/csv/PropInfo.json` 中的价格和币种；当前金币价格分别为 1000、650、500、1300。库存与余额共用 RuntimeMgr 的本地存储，主页和局内同步。失败续步沿用既有钻石费用逻辑，当前没有新增充值入口。

## 代码职责

- `Game/Home/HomeScene.ts`：三个页面、关卡滚动列表、图鉴详情、顶部和底部导航。
- `Game/Home/HomeNavigation.ts`：三页定义与滑动边界。
- `Game/Home/LobbyCatalog.ts`：道具文案、购买校验、关卡窗口计算、图鉴数据接口。
- `Game/Common/UI/ForestUI.ts`：程序图标、配色、面板、按钮、背景与点击处理。
- `Game/Common/UI/PlayerPanels.ts`：设置、个人信息、购买、暂停菜单。
- `Game/Match3/View/UI/MainUiCtrl.ts`：局内顶栏和道具栏布局，胜负结果接入。
- `Game/Common/UI/DialogPanel.ts`、`GameFailEncouragePanel.ts`：胜利／失败结果及后续操作。
- `Game/Match3/View/GroundViewCtrl.ts`：底格绘制。Graphics 使用独立子节点，避免与旧 Sprite 争用同一渲染节点。
