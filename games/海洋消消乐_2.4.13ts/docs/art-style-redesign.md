# 方块世界参考风格：美术重新设计方案

日期：2026-10-06。
状态：已接入项目，最终布局复测 2026-10-08。本文记录此次实现遵循的设计方向；实际验收范围见 reorganization-validation.md，美术原图及提示词见 art-preview/generation-prompts.md。

## 1. 产品定位

以菌子为基础棋子的休闲消除游戏。三页结构仍为商店、游戏、图鉴。

参考作者提供的方块世界 / Klotski 截图：明亮渐变背景、饱满立体按钮、圆润玩具质感图标、清晰粗体数字、集中突出的游戏内容。菌子承担棋子和图鉴内容，不引入寻找菌子、森林探索、采集旅行的题材包装。

去掉“林间小径”“林间补给”“探索下一段旅程”“采菌玩家”“收获满满”等上轮新增表达。对应使用关卡、商店、玩家、挑战成功等直接文案。取消额外的抒情副标题。

## 2. 统一美术规则

| 项目 | 新规范 |
| --- | --- |
| 主色 | 主页面使用明亮宝蓝向青蓝渐变；局内使用柔和紫蓝背景 |
| 材质 | 圆润塑料玩具质感；宽而柔和的高光，底部加深的厚度层，短投影 |
| 光源 | 固定左上光源，所有图标与按钮的高光方向一致 |
| 轮廓 | 大形状、少细节，较深同色外轮廓；小尺寸仍能辨认 |
| 文字 | 标题、关卡数字、主要按钮使用粗体，白字配深色描边；说明文字保持清晰易读 |
| 层次 | 背景安静，棋盘稍深，棋子明亮，当前关卡与主要按钮最突出 |
| 动效 | 短促按压、轻回弹、清晰消除反馈；装饰动画不持续干扰棋盘 |

初步色板：主页深蓝 #3C43B8 → 青蓝 #32BCEB；按钮蓝 #388CF2、绿 #79C82A、红 #EF5755；金币 #FFC943。局内背景 #B2A6EF → #9BC8F4，棋盘外框 #3F507A，底格 #6679A4 / #60729A，弹窗内页 #FFF0D8。最终以整屏效果和用户菌子素材的辨识度调整。

## 3. 三页主页

### 游戏页

- 顶部只有头像、体力、金币和右侧菜单。使用有厚度的头像框、立体心形、金币与浅色数字底条。
- 关卡区采用参考图的纵向轨道、大块圆角关卡按钮。常见手机屏幕同时呈现约 3～4 个主要节点，当前关卡最大、最亮，数字更突出。
- 当前关卡用鲜绿色，已通过关卡用蓝色，只显示紧邻的一关锁定预览，使用低饱和度蓝灰色和小锁；朝未解锁方向拖动后回弹，不能浏览更远关卡。
- 底部上方放“第 N 关 / 开始游戏”主按钮。保留自然纵向滚动，将分页与定位逻辑收进列表，移除现在显眼的左右翻段箭头。
- 底部三个页签采用立体图标：商店小铺、菌子棋子组合、菌子图鉴册。选中页签略放大并有凸起底座。
- 页面不增加活动入口、森林景物或采集进度条。

### 商店页

- 共用主页顶栏和底部导航；标题为“商店”。
- 道具摆在浅色圆角商品卡中，避免多层厚边框，图标占视觉中心。显示名称、数量、金币价格和购买按钮。
- 爆破弹、木锤、重排、十字消除均使用独立立体道具插画，不再套用“彩色方块加白色符号”的应用图标样式。
- 保留现有金币购买、库存刷新与余额不足反馈。

### 图鉴页

- 标题为“图鉴”；用圆角厚卡片展示菌子图片和名称，详细文字放进弹窗。
- 卡片中的菌子与棋盘中的同种菌子保持造型、配色一致，可以使用不同尺寸的导出图。
- 详情显示菌子大图、名称、介绍和作者后续提供的资料。当前保留资料占位。
- 不新增发现、采集或图鉴解锁规则。

## 4. 局内棋盘

- 顶部保留关卡、剩余步数和目标；关键数字放大。让棋盘向上靠近目标区，缩小当前顶部空白。
- 棋盘视觉宽度占可用区域约 88%～94%，随行列数调整高度与位置；底部为道具栏。
- 使用连续的深蓝灰棋盘底座，外轮廓沿有效格子连接。内部格子采用低对比交错底色和轻凹槽，保留关卡空洞及不规则轮廓。
- 去掉每一格显眼的独立外框和厚阴影，避免棋盘像一堆单独贴上的小卡片。
- 棋子投影很短，亮度高于底格；基础菌子与特殊元素具有一致的视觉体积。
- 基础菌子由作者设计。建议使用圆润菌盖、明确主色、大色块和适量纹理；缩到单格后仍能快速区分。现有素材用于布局阶段，正式交付以作者素材为准。

## 5. 特殊元素与道具

保留已确认的种类和消除规则，重新统一材质。

| 元素 | 造型方向 | 主要识别点 |
| --- | --- | --- |
| 横向清除 | 蓝色圆润短胶囊，两端有实体箭头 | 横向轮廓与双端箭头 |
| 纵向清除 | 橙色圆润短胶囊，两端有实体箭头 | 纵向轮廓与双端箭头 |
| 爆破弹 | 紫色圆球，明确的顶部小引信和少量亮点 | 大球体与引信 |
| 小爆弹 | 橙色小圆球，简短引信 | 比大爆破弹更小、更简洁 |
| 流星球 | 青绿色球体配短而宽的彗尾 | 斜向飞行轮廓 |
| 彩虹球 | 饱满球体上分布红、黄、绿、蓝宽色带 | 多彩完整球体 |

方向同时由形状和颜色表达；特殊元素轮廓与菌子明显区分。彩虹球高光控制在一处，避免大面积白光遮住色带。

道具栏采用立体道具加浅蓝圆角立体底座，右下角显示绿色加号或数量。木锤有锤头和握柄；重排用两枚棋子围绕交换的造型；十字消除用蓝色实体十字能量件。道具栏图标与商店商品图共用同一美术来源。

扫光、爆破波、流星飞行与彩虹连线继续由程序实现。装饰碎点少量使用，特效后应立即看清棋盘变化。

## 6. 弹窗和结算

- 通用弹窗：蓝色立体标题条、奶油色内页、厚圆角边框、右上红色圆角关闭按钮。
- 个人信息：头像、昵称、ID、当前关卡徽章，参考作者图 2 的紧凑布局。
- 设置：三个大圆角开关分别表示音乐、音效、震动；开为绿、关为灰，配文字说明。右侧展开菜单仅保留设置和信息。
- 胜利：标题“挑战成功”，立体金星、关卡、奖励信息、继续与返回按钮。奖励信息使用真实结算数据，不用余额冒充本关奖励。
- 失败：标题“挑战未完成”，清楚显示剩余目标，提供重试、继续和返回；减少装饰，保持信息顺序稳定。
- 续步币种属于玩法配置，按既有逻辑保留；本轮美术方案不另行修改费用。

## 7. 落地顺序与验收

1. 先制作游戏主页与局内棋盘的两张完整效果稿，同时定下一个关卡按钮、一张弹窗和六种特殊元素的材质样例。
2. 以整屏对照参考图：饱和度、厚度、数字大小、图标体积和棋盘占比必须一致协调。
3. 确定整屏方向后，再制作商店、图鉴、个人信息、设置及胜负结算，复用同一套组件与美术。
4. 接入工程。核心按钮、道具和特殊元素使用统一贴图，程序承担布局、按压反馈与消除特效；无需引入实时 3D 场景。
5. 在手机尺寸下检查点击区域、文字截断、棋子辨识度与效果遮挡，并回归购买、道具使用、最后一步结算、重试、返回和设置保存。
