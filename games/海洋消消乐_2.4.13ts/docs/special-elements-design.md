## 程序特效

`Game/Match3/View/SpecialEffects.ts` 管理以下效果：

- 横竖扫光：从起点向两侧展开，限制在当前棋盘边缘内，约 0.5 秒。
- 范围爆炸：扩散圆环和八颗碎点；普通爆破、小爆弹、双爆破复用同一效果，调整大小和时长。
- 流星飞行：短暂起飞、弧线移动、方向随轨迹变化、落点圆环；总时长使用原飞行时间配置加起飞时间。
- 彩虹：彩球放大、转动、淡出，目标连线和环形提示；组合复用对应扫光、爆炸或飞行动效。
- 组合：保留 100–104 的全部 15 种无序组合分派。双直线用十字扫光，双爆破用扩大冲击环，其他组合由原规则调度基础效果。

效果层接收坐标和类型，不决定伤害、收集或掉落范围。圆环用于表达爆炸力度，实际受影响的格子仍由规则层控制；没有新增屏幕震动或持续闪白。部分旧组合的等待动画缩短，不能把本次替换理解为保持每个旧动画时长。

## 代码与资源边界

| 文件 | 职责 |
| --- | --- |
| `View/SpecialPieceArt.ts` | 六种特殊元素编号到 ToyArt 生产图集的映射 |
| `View/SpecialEffects.ts` | Cocos Graphics、飞行 Sprite、最多 64 个并发视觉节点及复用 |
| `View/EffectTimeline.ts` | 完成／取消语义；取消返回 false，阻止过期的游戏完成回调 |
| `View/ItemBasicCellCtrl.ts` | 棋盘外观接入，复用节点时恢复单格尺寸 |
| `View/EffLayerCtrl.ts` | 原业务效果入口到新程序特效的适配 |
| `Model/BombModel.ts` | 原规则，等待效果后检查是否取消 |
| `ResCtrl.ts`、`CollectItemCtrl.ts`、`PropItemCtrl.ts` | 棋子、目标及相关道具展示的外观入口 |
| `Debug/SpecialValidation.ts` | 六个单体与十五个组合的临时测试关 |

当前使用 `texture/toy-ui/toy-atlas.png` 生产图集。2026-10-08 已删除旧程序光栅化实现、生成脚本和六张旧小图，运行时仅从 ToyArt 取得共享 SpriteFrame。

超过视觉节点上限的效果仍会正常完成规则回调，不因省略视觉节点卡住结算。返回主页、重开或销毁场景时取消特效；单元测试覆盖超限、回收、取消和重新启动。

## 查看与验收

浏览器调试环境：加载到主页 → **特殊元素验收** → 选择单体或组合 → 把棋盘中心偏左的特殊元素向右交换一格。

该入口生成内存中的 9998 关，不修改正式关卡 JSON。测试关使用 99 步和较高收集目标，不设置关卡奖励。微信环境隐藏此入口。真实浏览器验收范围与已知问题见 [整理与验收记录](reorganization-validation.md)。

## 2026-10-08 特效优化

流星采用实体图标、42/25/10 单位的分层曲线尾迹、少量星点和落点冲击；彩虹采用彩色短光束、移动光点和命中星芒，结束命中后才执行回调。取消、重开仍返回 false，不触发上一局消除。横向与纵向效果保留。
