# funTools 部署与运营

## 本地启动

使用 Python 3.11，在项目目录创建虚拟环境并安装 `requirements.txt`。新功能额外依赖 `qrcode[pil]`、`itsdangerous`、`python-multipart`，不需要 Node 构建步骤，也不依赖外部 CDN。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py --port 8000
```

在另一个终端启动独立管理站：

```powershell
.venv\Scripts\python admin_main.py --port 8001
```

前台为 `http://127.0.0.1:8000/`；后台为 `http://127.0.0.1:8001/login`。两个进程可以独立停止或启动。前台不挂载后台路由。

Windows 也可双击 `scripts/run_site.bat`、`scripts/run_admin.bat`。脚本优先使用项目虚拟环境，没有虚拟环境时使用系统 Python。

## 管理密码

首次启动后台，会在终端显示一次随机密码；存储的是 PBKDF2 哈希，后续启动不会显示原密码。若忘记密码或需要更新，停止后台后执行：

```powershell
python admin_main.py --set-password
```

也可由运行环境提供至少 12 位的 `FUNTOOLS_ADMIN_PASSWORD`。该环境变量优先于本地密码文件。切换密码后重启后台，已有会话会失效。生产环境使用密码管理服务注入，不把密码写入版本库。

会话有效期为 8 小时，Cookie 使用 HttpOnly / SameSite=Strict；HTTPS 下设置 Secure。所有后台修改接口需要会话和 CSRF 校验。登录限流为每地址 5 分钟最多 8 次尝试（单进程）。

## 工具上下架与变现

在管理站调整开关后点击“保存配置”。前台每个新请求读取 SQLite 最新配置，无需重启。下架会移除导航和卡片，并拦截工具地址与对应后端接口；已在用户浏览器内运行的本地代码不能被远程撤回。

打赏支持标题和收款二维码，开启后显示入口与弹窗。广告采用图片、标题、HTTP/HTTPS 跳转链接，展示在首页及工具页并标注“广告”。两种变现默认关闭；开启前必须上传图片，广告还必须填写链接。本版本不提供广告联盟脚本或支付订单处理。

上传仅接受 5 MB、1600 万像素以内的 PNG/JPG/WebP；后端重新编码为 PNG 并生成随机文件名。替换图片后原图片保留在上传目录，便于已有页面继续访问。没有上传用户的真实收款二维码或广告素材。

## 数据与备份

默认数据目录为项目 `data/`，也可用环境变量 `FUNTOOLS_DATA_DIR` 指定绝对目录。前台和后台必须使用同一个目录。

- `site.db`：工具开关、变现配置和版本号；SQLite 事务避免部分写入，版本冲突返回 409。
- `admin.json`：密码哈希及会话签名密钥，不能发布或共享。
- `uploads/`：公开二维码与广告图片，只有此目录通过 `/media/` 提供访问。

`data/` 已被 Git 忽略。备份时停止两个服务后复制整个数据目录，或使用 SQLite 在线备份机制并同时保存上传图片。多进程必须共享本地磁盘，不适用于无共享存储的多机部署。

## 本机文件夹工具

仅在自己的电脑使用时启用：

```powershell
$env:FUNTOOLS_LOCAL_MODE = '1'
python main.py
```

使用 `127.0.0.1`、`localhost` 或 `::1` 打开页面。接口要求回环连接、本机 Host 和同源请求，前端自动添加校验头。公开部署保持此变量未设置；不要在反向代理后启用本机模式。

## 公网部署

使用进程管理器分别运行前台与后台，并把工作目录设为项目根目录。应用使用绝对资源路径，也支持从其他目录通过 `--app-dir` 启动。

```bash
uvicorn main:app --host 127.0.0.1 --port 8000 --proxy-headers --forwarded-allow-ips=127.0.0.1 --no-access-log
uvicorn admin_main:app --host 127.0.0.1 --port 8001 --proxy-headers --forwarded-allow-ips=127.0.0.1 --no-access-log
```

将 `deploy/nginx.example.conf` 中的域名和证书路径替换为自己的配置。前后台使用两个域名；建议后台再加运维 IP 白名单。Uvicorn 不对公网开放，反向代理覆盖客户端代理头，且仅信任指定的代理地址。若代理不在本机，替换为实际可信代理 IP，不能使用 `*`。

直接执行 `main.py` / `admin_main.py` 时禁用代理头，因此本地预览的 IP 小工具会由浏览器查询 ipify。生产部署若按上述命令启用可信代理，显示访问者地址。

前台请求体限制为 24 MB；AI 去水印限制 400 万像素、单进程同时一次推理，繁忙返回 429。建议单 worker 运行含 LaMa 的站点，避免每个 worker 各加载一份模型。Nginx 示例为去水印接口增加每 IP 限流。

## 已知边界与上线检查

- AI 去水印沿用现有 IOPaint/LaMa，需先运行 `python scripts/download_remove_watermark_model.py` 下载模型，再用真实图片测试推理。本次未重新下载或完整验证模型推理。
- 图片工具支持单张 PNG/JPG/WebP，最高 20 MB、4000 万像素；透明图片转 JPG 使用白底，动画图片处理首帧。压缩并不保证每次更小，会显示前后大小。
- 二维码最长 1800 字符，但密集多字节内容可能达到二维码容量上限，界面会显示错误。哈希与二维码内容不写文件，避免在代理开启请求体日志。
- 公网 IP 第三方查询取决于本地网络和 ipify 可用性，失败时显示重试提示。
- 上线前替换域名/证书，配置自己的管理密码、收款二维码和广告素材，并验证 HTTPS、真实网络出口 IP、模型推理和数据备份。当前交付是本地可运行的网站，未绑定域名或发布到外部服务器。
